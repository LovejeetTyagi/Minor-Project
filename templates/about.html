About the Project

This is a B.Tech CSE semester minor project. It predicts the likelihood of heart disease from 13 clinical features using a supervised machine learning model.

How it works

  • Dataset: UCI Heart Disease dataset (Kaggle version).
  • Preprocessing: duplicate removal and feature scaling (StandardScaler).
  • Models compared: Logistic Regression, SVM, KNN, Random Forest (5-fold cross-validation).
  • Model in use now: {{ model_name }}.
  • Web app: Flask, with a JSON API at /api/predict.

Input features

age, sex, cp, trestbps, chol, fbs, restecg, thalach, exang, oldpeak, slope, ca, thal.

Disclaimer: This project is for learning only. It is not a medical device and must not be used for diagnosis or treatment decisions.
